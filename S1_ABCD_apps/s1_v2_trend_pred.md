# S1 v2 Trend Predict 分析說明

本文記錄 `s1_v2_combo_trend_analyze.py` 在 `backtest` mode 的分析與預測邏輯。


內容包括：
- backtest mode 窗口期 / 核對期定義
- >=3 基礎條件用途
- >=5 強勢條件用途
- ABCD H/- 走勢說明
- 分組走勢與球數走趨
- 權重分析細節
- 強 / 中 / 弱評分規則
- A/B/C/D 配額規則
- backtest 核對預測明細格式
- v2 目前分析重點

## 1. 主要參數

```python
SELECT_GROUPS = (1, 2, 3, 4)
COMB_MATCH_MODE = ">="
COMBINATION_TAKE_COUNT = 3
STRONG_COMBINATION_TAKE_COUNT = 5
LOTTO_LIST = False
```

含義：

- `SELECT_GROUPS`：查詢分組，例如 `(1, 2, 3, 4)` = ABCD，`(1, 2, 3)` = ABC，`(2, 3, 4)` = BCD。
- `COMBINATION_TAKE_COUNT = 3`：基礎條件，用來判斷組合是否仍有基本出球動能。
- `STRONG_COMBINATION_TAKE_COUNT = 5`：強勢條件，用來判斷組合是否仍維持高球數連續。
- `COMB_MATCH_MODE = ">="`：球數比對模式。
- `LOTTO_LIST = False`：開獎號按 A/B/C/D 分組顯示。

## 2. Backtest 窗口期

`backtest` mode 的窗口期不包括核對期。

例如回測某一期時：

- 窗口期：用來分析走勢與產生預測。
- 核對期：用來核對剛才的預測是否命中。

顯示格式：

```text
近 19期：2026-08-08，H，[1,3,7]，[]，[31]，[32] /> 5 球
```

其中：

- `H` 代表該期符合基礎條件。
- `-` 代表該期不符合基礎條件。
- 分組號碼順序為 A、B、C、D。
- 特號在所屬組別內以 `*` 顯示，並計 1 球。

## 3. 基礎條件與強勢條件

v2 版同時看兩層條件。

### 基礎條件 `>= 3`

```python
COMBINATION_TAKE_COUNT = 3
```

用途：

- 判斷大組合是否仍有基本出球動能。
- 若 `>=3` 長期連續，代表組合未真正斷線。
- 適合觀察「基礎連續期」。

顯示例子：

```text
基礎條件 >= 3 球，查詢 19 / 19 期統計 = 19期 (100 %)
```

### 強勢條件 `>= 5`

```python
STRONG_COMBINATION_TAKE_COUNT = 5
```

用途：

- 判斷大組合是否仍維持高球數強勢。
- 若 `>=3` 未斷，但 `>=5` 開始出現 `-`，代表「基礎未斷，強勢轉弱」。
- 適合觀察「強勢連續期 / 強勢斷續期」。

顯示例子：

```text
強勢條件 >= 5 球，查詢 16 / 19 期統計 = 16期 (84 %)
```

## 4. 開獎期組別走勢

這部分用強勢條件 `>=5` 生成整體 H/- 走勢。

```text
----- ABCD 開獎期組別走勢 -----
查詢ABCD N 期 >= 5 球，分析連續期/ 斷續期
ABCD ＝ HHHHHHHHHHHHHHH-H--
```

含義：

- `H`：該期符合強勢條件，例如 ABCD 開出 `>=5` 球。
- `-`：該期不符合強勢條件，例如 ABCD 開出 `<=4` 球。

這行主要用來判斷大局：

```text
ABCD >=5 是否開始不穩
```

## 5. 分組走勢序列

每組只看該組在該期是否有開出，不看開出幾球。

例子：

```text
A組 走勢序列：A--AAAAA-AAA-AAAAAA  15/19
B組 走勢序列：-B-BBBBBBBB--BBBB-B  14/19
C組 走勢序列：CCCC-CCCCCCCCCCCC-C  17/19
D組 走勢序列：DDDDDDDDD-DDDD---D-  14/19
```

含義：

- 字母代表該組該期有出球。
- `-` 代表該組該期沒有出球。
- `15/19` 代表 19 期內 A 組出現 15 期。

用途：

- 判斷每個分組是否連續活躍。
- 協助區分「整體強勢斷了，但某組仍未斷」。

## 6. 分組球數走趨

每期計算該組開出幾球，0 球顯示 `-`。

例子：

```text
A組 球數走趨：3--13222-311-142211 = 29 球次 / 133 = 21.8%
B組 球數走趨：-3-21212211--2113-1 = 23 球次 / 133 = 17.3%
C組 球數走趨：1133-121223331212-2 = 33 球次 / 133 = 24.8%
D組 球數走趨：112111221-1232---2- = 22 球次 / 133 = 16.5%
```

計算方法：

```text
總球次 = 窗口期數 x 7
```

例如窗口期 19：

```text
19 x 7 = 133 球次
```

每組球次百分比：

```text
該組球次 / 總球次
```

用途：

- 判斷各組實際出球權重。
- 比「有無出現」更細緻。
- 可用作候選池配額分析。

## 7. 權重預測邏輯

權重預測分兩部分：

1. 大局預測：判斷下期偏向 `>=5` 還是 `<=4`。
2. 分組配額：判斷 A/B/C/D 各組建議取幾球。

### 7.1 大局預測

使用強勢條件 `>=5` 的近期狀態。

目前規則：

```python
is_unstable = strong_break_streak > 0 or strong_hot_streak <= 1
```

如果強勢斷續期大於 0，或最近強勢連續期少於等於 1：

```text
ABCD >=5 強勢不穩，預測偏向 <=4 球
```

否則：

```text
ABCD >=5 強勢連續，預測偏向維持 >=5 球
```

例子：

```text
大局：ABCD >=5 強勢不穩，預測偏向 <= 4 球
強勢條件命中：16/19，最近強勢連續 0 期，強勢斷續 2 期
```

### 7.2 分組強中弱評分

每組用三個指標加分：

1. 出現率
2. 球次佔比
3. 最近連續

#### 出現率分數

```text
出現率 >= 75%：3 分
出現率 >= 60%：2 分
其他：1 分
```

#### 球次佔比分數

```text
球次佔比 >= 22%：3 分
球次佔比 >= 16%：2 分
其他：1 分
```

#### 最近連續分數

```text
最近連續 >= 3 期：2 分
最近連續 >= 1 期：1 分
其他：0 分
```

#### 分級

```text
總分 >= 7：強
總分 >= 5：中
其他：弱
```

## 8. 分組配額規則

目前用簡單保守配額。

A / D 組只有 9 球，配額較細：

```text
強：3 球
中：2 球
弱：1 球
```

B / C 組有 11 球，配額較大：

```text
強：4 球
中：3 球
弱：2 球
```

例子：

```text
A組：強，建議配額 3 球
B組：中，建議配額 3 球
C組：強，建議配額 4 球
D組：弱，建議配額 1 球
建議候選池：A3 + B3 + C4 + D1 = 11 球
```

## 9. Backtest 核對預測明細

backtest mode 會用核對期驗證預測。

顯示例子：

```text
----- backtest mode 核對預測明細 -----
大局：ABCD >=5 強勢不穩，預測偏向 <= 4 球
建議候選池：A3 + B3 + C4 + D1 = 11 球
--
核對期 2026-10-03 開獎號 : [8]，[]，[23,29,31]，[34] /> 5 球
ABCD 大局預測 <= 4，不中
預測命中組別球數  A[預測 3 ＝ 1]，B[預測 3 ＝ 0]，C[預測 4 ＝ 3]，D[預測 1 ＝ 1] /> 預測 11球，命中 5 球
```

### 大局核對

如果預測 `<=4`，但核對期實際開出 `>=5`：

```text
大局預測不中
```

如果預測 `>=5`，核對期也開出 `>=5`：

```text
大局預測中
```

### 分組配額核對

格式：

```text
A[預測 3 ＝ 1]
```

含義：

- A 組預測配額 3 球。
- 核對期 A 組實際開出 1 球。

最後：

```text
預測 11球，命中 5 球
```

含義：

- 預測候選池總配額為 11 球。
- 核對期在自選分組內實際開出 5 球。

這裡核對的是「分組配額方向」，不是具體號碼命中。

## 10. 分析重點

目前 v2 的重點不是直接選號，而是回答兩個問題：

1. 下期大局偏向 `>=5` 還是 `<=4`？
2. 如果要組候選池，A/B/C/D 各組應該如何分配配額？

核心觀察：

```text
>=3 看基礎走勢是否仍未斷。
>=5 看強勢走勢是否開始轉弱。
分組球次與分組連續用來決定候選池配額。
```

目前權重預測屬於第一版規則，目標是先讓 backtest 可觀察、可調參，再逐步修正配額公式。
