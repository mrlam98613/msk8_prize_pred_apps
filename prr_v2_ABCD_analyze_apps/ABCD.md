可以，這支程式現在的核心可以整理成這樣：
ABCD 權重預測核心
1. ABCD 四組獨立分析
   - A：1-9
   - B：10-20
   - C：21-31
   - D：32-40
   - 每組用同一個窗口期，例如 24 期。
   - 條件是該組在每期開獎中 >= 1 球才列入分析樣本。
2. 權重熱門號
   - 在每組窗口期內，統計球號出現次數。
   - 再加入遠近權重：
     - 越近期出現，分數越高。
     - 越遠期出現，分數越低。
   - 最後得到每組的「權重熱號」排序。
   - 這是基礎熱度，不是最終投注球。
3. 未出現球號
   - 統計整個窗口期內沒有出現過的球號。
   - 分 A/B/C/D 顯示。
   - 作用是提示冷號、漏號，不一定直接入選。
4. 高頻膽號
   - 從條件查詢後的開獎期中，再找「同期配對」。
   - 一個球號必須在合條件期內出現 >= 2 次，並且多次與其他球同場出現，才列為高頻膽。
   - 高頻膽不是單純出現次數最高，而是有重複配對軌跡。
5. 高頻配腳號
   - 以高頻膽號為核心，找與它同場出現的伴號。
   - 配腳可按出現次數、遠近期、同場次序排序。
   - 實際選取時，可以保留隨機成分，讓不同配腳都有機會入選，不要固定死同一批球。

   出現次數 count = 1
   最近位置 latest_rank = 12
   遠近權重 recent_score = 0.5
   短期重複 repeat_score = 0
   總分 score = 1 + 0.5 + 0 = 1.5

6. 避開最近一期重複
   - 最終候選球產生時，優先避開最近 1 期的開獎號。
   - 目標是避免總候選球與上一期重複太多。
   - 如果候選不足，才放寬補位。
7. 最終候選球組成
   - 每組按配額，例如：
   A=3, B=4, C=4, D=3

   高頻膽號 -> 高頻配腳號 -> 權重熱號補滿
