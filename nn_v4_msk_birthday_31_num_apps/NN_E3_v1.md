現在 E3_v1.py 的發球預測，核心重點在 1-9 雙球組合統計。
流程是這樣：
1. 每一期回測，先決定核對期
   例如核對 2026-08-29。
2. 取窗口期資料
   例如窗口期 12 或 24，只取核對期之前的資料，不包括核對期。
3. 在窗口期內，只看 1-9 號
   N1-N6 正號 + N7 特號，如果特號在 1-9，也當整數球加入統計。
4. 每一期如果 1-9 有 2 球或以上，就拆成雙球組合
   例如：


[1,3,7] -> (1,3), (1,7), (3,7)
[7,8,9] -> (7,8), (7,9), (8,9)

(1,7) 出現 4 次
(7,9) 出現 3 次
(4,7) 出現 2 次

排序重點是：
- 第一：雙球組合出現次數多
- 第二：最近出現，即索引越細越優先
- 第三：原本組合 index

發 3 球時，不是直接取一組 pair，而是將前面高分 pair 轉成單球分數
例如：


(1,7) = 4 次，但上一期已出 -> 扣分
(7,9) = 3 次，但上一期已出 -> 扣分
(4,7) = 2 次，未與上一期重複 -> 提升
(5,7) = 2 次，未與上一期重複 -> 提升
(7,8) = 1 次，未與上一期重複 -> 候補

樣會兼顧：
- 人氣核心
- pair 關連
- 遠近期衰減
- 冷號回補
- 避免上一期重複 2 球以上
